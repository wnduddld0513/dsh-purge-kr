# 1.7.13

- **업데이트 진단이 더 정확해집니다(#225)**: 응답이 크기 상한을 넘으면 상한과 확인된 크기를 표시합니다; 주 소스와 대체 소스가 모두 실패했거나 만료된 캐시만 있으면 검사 결과를 미지로 표시하고 마지막으로 확인한 버전을 유지하며, 만료된 캐시로 자동 설치를 시작하지 않습니다. 전체 목록을 쓸 수 없을 때는 GitHub 현재 정식 버전 번호를 읽기 전용으로 조회해 확인할 수 있지만, 그것을 설치 가능한 대상으로 삼지는 않습니다.
- **릴리스 본문을 버전별로 분리합니다(#225/#226)**: GitHub Release 본문은 `docs/releases/<version>.md` 를 쓰고, 과거 기록을 다시 누적하지 않습니다; 한 버전 요약의 상한은 **8 KiB** 이고 넘으면 릴리스 자체를 거부합니다.
- **버전 번호 규칙(#222)**: 패치 번호는 0–99 를 쓰고 앞자리 0 을 채우지 않습니다; 과거 1.6.100/1.6.101 은 원래 태그와 본문을 유지합니다.
- 기존 다운로드 제한, 출처 검증, SHA256 검증, 호스트 패치는 바뀌지 않습니다.

검증: 테스트 650건 통과 / 29건 플랫폼별 건너뜀; UI, 문서 예산, 클라이언트 일관성, 릴리스 패키지 smoke 통과.

전체 이력과 진단은 [release-notes.md](https://github.com/kingcharleslzy-ai/dsh-purge/blob/master/release-notes.md) 를 봅니다.
