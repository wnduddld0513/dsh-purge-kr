# 1.7.14

- **사이드바와 플러그인 상세가 같은 설정을 씁니다(#220)**: 두 진입점이 같은 기존 설정 컴포넌트를 마운트합니다; 사이드바에서 업데이트 간격을 바꾸면 상세 페이지에 즉시 보이고, 반대 방향도 같습니다. 두 컴포넌트를 동시에 열거나 행 상세를 다시 마운트해도 디스크에 저장된 값을 읽습니다. 유지보수 페이지는 선호를 함께 갱신하고 중복 오류를 합치며, 별개의 오류는 그대로 남깁니다.
- **상세 페이지 패키징을 보완합니다**: 묶음 패키지 상세 페이지와 행 상세 페이지가 모두 기존 설정 컴포넌트를 씁니다; `docs/detail.*.md`, 아이콘, locale 의 패키징 경로를 채웠고 목록 요약은 짧게 유지합니다.
- 호스트 패치, 주입 본문, CLI 동작은 바뀌지 않습니다; 버전은 1.7.x 두 자리 패치 번호를 유지합니다.

검증: 테스트 650건 통과 / 29건 플랫폼별 건너뜀; 패널 테스트 실패 0건; Chrome 에서 "사이드바 → 상세 → 사이드바" 와 행 상세 재마운트(디스크에서 24시간 값 복구)를 실제로 확인; UI, 클라이언트 일관성, 릴리스 패키지 smoke 통과.

전체 이력은 [release-notes.md](https://github.com/kingcharleslzy-ai/dsh-purge/blob/master/release-notes.md) 를 봅니다.
