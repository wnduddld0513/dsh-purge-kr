# 1.7.15

- **#240**: 새 세션이 호스트 권한을 따르게 했습니다. 권한·실행 경계 패치 14건은 명시적 opt-in 으로 바꾸고, 옛 버전 권한 패치는 백업을 기준으로 다시 적용해 이전하며 충돌이 나면 원본을 보존합니다.
- **#241**: Windows 패키지 교체 전에 서명 sidecar 20개의 SHA256 과 ASAR 매니페스트 연결을 검증합니다.
- **#232**: 패키지 아이콘을 선언하고, 사이드바에는 같은 그림의 알파 선화를 씁니다.
- **#233**: 호출하는 곳이 없던 settings-shell 을 지웠습니다. 클라이언트 산출물은 그대로입니다.

검증: 659개 통과 / 플랫폼별 29개 스킵. 패널 실패 0건. 권한 경계와 서명 회귀 통과.
