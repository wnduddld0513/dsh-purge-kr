# 1.7.18

- **권한 패치 기본 켜짐**: #6 #7 #8 #9 #10 #13 #14 #15 #16 #35 #51 #59 #60 #62 를 하나씩 켜던 방식에서 **기본 켜짐**으로 바꾸고 그룹 스위치 하나로 묶었습니다. 끄더라도 이미 기록된 파일이 바로 되돌아가지는 않고, 다음 「적용」에서 되돌립니다.
- **컨텍스트 관리 그룹**: #18(반복 호출 알림)과 #19(도구 결과 다듬기)를 두 번째 그룹 스위치로 묶었고 **기본 꺼짐**입니다. 옛 설정에 손으로 적어 둔 `extraPatches: [18,19]` 는 스위치가 켜진 상태로 자동 이전됩니다.
- **상태 페이지 재구성**: 주 숫자를 '건' 단위로 세고, 적용됨 · 적용 대기 · 사용 안 함 · 이 기기에서 해당 없음 네 가지로 나눕니다. 해당 없음은 분모에서 빠집니다.
- 상태 페이지에 패치 그룹 스위치, 상태 필터, 상태별 설명, 세 단계 기록 절차를 넣었습니다. 「새로 고침」은 오른쪽 위 '마지막 검사 · 눌러서 새로 고침'으로 바뀌었습니다.
- 상태 페이지 좁은 화면 대응: 640px 이하에서는 스위치와 단계를 한 줄로, 네 칸은 2×2 로 배치합니다. 360px 이하에서는 표 열 너비를 고정해 컨테이너를 넘지 않습니다.
- `AGENTS.md` 517줄을 AGENTS.md 와 maintenance-archive · troubleshooting · compatibility 네 갈래로 나눴습니다.
