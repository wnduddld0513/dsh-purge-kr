# Inspector 의 Cordis 트리 스냅샷 한도 초과

일부 Inspector 빌드는 payload 크기로 가지치기를 하지만, state 에 쓸 때는 topic 과 타임스탬프까지 함께 계량한다. 트리가 바이트 상한에 가까우면 가지치기에 성공해도 쓰기에서 다시 한도를 넘을 수 있다.

호스트와 렌더러가 기록 껍데기에 각각 1 KiB 를 남겨 둔다. 그래도 Cordis 트리가 state 한도 초과로 되돌아오면 버퍼는 이전 프레임을 유지하며, 다음 갱신은 다시 발행할 수 있다. 다른 topic 의 한도 초과, 수집기 오류, 직렬화 오류, 리스너 예외는 호스트의 기존 의미대로 계속 보고한다. 구현은 되돌린 뒤의 한도 초과 분기만 정확히 겨냥하며, 발행 콜백 전체를 감싸지 않는다.

회귀 테스트는 버퍼 메서드를 직접 실행해 정상 적재, 한도 초과 시 옛 값 유지, 옛 값이 없을 때 철회, 다른 topic 의 한도 초과, 예외 전파를 확인한다. `node --test test/inspector-budget.test.mjs` 로 실행한다.
